# Changelog

## 0.1.0 - Initial implementation
- Dimensional parameter resolver with restricted arithmetic expressions and dependency detection.
- Parametric circle, rect, line, polyline, arc, true-radius slot, polar-hole-pattern, and center-mark primitives.
- Horizontal/vertical/aligned linear dimensions, leader annotations, diameter/radius callouts, and circular-hole-pattern notes.
- Vector SVG, printable 17x11-inch PDF, blue-style SVG/PNG preview, true-unit R2010 DXF with CAD dimension entities.
- Revision commands with automatic dependent geometry recalculation and audit trails.
- Geometric check expressions, unconfirmed-parameter warnings, and a machine-readable manifest.
- GitHub Actions workflow and initial local stdio MCP bridge.
- Seven automated tests of geometry, revision consistency, export correctness and expression safety.
