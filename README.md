# ReapWhatUSnow — SnowForge Blueprints v0.1

**A parameter-driven mechanical blueprint tool designed for an AI assistant to operate.**

Describe a mechanism in ordinary English -> assistant converts the description to structured, revisable drawing specifications -> SnowForge computes the geometry and dimensions -> exports **true-size DXF**, printable **17 × 11 in PDF**, **SVG**, blueprint-style **PNG**, a validation manifest, and the original editable JSON.

A sample drawing is generated by GitHub Actions as a downloadable workflow artifact.

## Installation

Python 3.10+ required.

```bash
python -m pip install -e .
python -m snowforge build \
  --input examples/8_on_6_5_mounting_flange.json \
  --out build/flange
```

Or open **Actions > Build SnowForge Blueprints > Run workflow** in GitHub, choose the path to your saved JSON drawing, and download the `snowforge-blueprint` workflow artifact.

## Change a part dimension

```bash
python -m snowforge revise \
  --input examples/8_on_6_5_mounting_flange.json \
  --set bolt_hole_diameter=0.625 \
  --out-spec build/flange_rev_b.json \
  --note "Increase holes to 5/8 inch" \
  --render-out build/flange_rev_b
```

All dependent geometry, pattern callouts, checks, and drawing revision fields update. The source JSON remains unchanged.

## The plain-language workflow with ChatGPT

Tell ChatGPT: "Make a plan, front, and side blueprint for a 6-inch by 4-inch mounting plate, with a half-inch center hole. Then move the hole 3/4 inch to the right." ChatGPT converts the design into the JSON schema; SnowForge renders and tracks revisions. You do **not** need to hand-edit formulas if your assistant has access to the repo files and a Python execution environment.

The CLI does not itself parse arbitrary English; it generates drawings from explicit parametric geometry. GitHub hosts files and runs the Actions job; **GitHub alone does not make this a callable ChatGPT tool**. For tool integration there is an optional **stdio MCP server** at `snowforge/mcp_server.py` with tools `analyze_blueprint`, `revise_blueprint`, and `generate_blueprint_files`:

```bash
python -m pip install -e '.[mcp]'
python -m snowforge.mcp_server
```

This MCP server operates on the host machine and writes output to that machine's filesystem. A remote ChatGPT-connected MCP integration needs deployment, authentication, and file delivery wiring, which is **not** included in v0.1. Until then ChatGPT can work with this source and invoke the Python CLI when given an execution environment.

## Drawings vs engineering validation

- **True-scale geometry:** DXF model space is 1:1 in the selected unit. A layout and dimensioned orthographic views are provided in the SVG/PDF.
- **Deterministic dimensions:** linear, radius, and diameter annotations are calculated from actual modeled geometry; hole patterns compute count/size/pitch circle.
- **Design history:** `revise` stores from/to values and increments A -> B -> C. Git commits preserve earlier versions.
- **Unknowns remain visible:** `parameter_status` flags `assumed`, `derived`, or `confirmed` dimensions; unspecified tolerances, loads, fits, and material are not silently solved.
- **Geometry checks:** expressions can express minimum feature land, clearance, stroke, and other purely geometric constraints. Failing checks produce a nonzero exit code.
- **Not yet:** automatic 3D modeling, full dimension/tolerance standards, industrial CAD constraints, welds or material stress verification, associative projections, clash analysis, ISO/ASME drawing certification, direct in-chat file retrieval from a hosted server.

## Supported geometry

| Entity | Inputs | Notes |
| --- | --- | --- |
| `circle` | `center`, `r` | bore, hole, OD |
| `polar_holes` | `center`, `count`, `pitch_radius`, `hole_radius`, `start_deg` | true bolt pattern |
| `rect` | `origin`, `width`, `height` | plates, sections |
| `line` | `p1`, `p2` | edges and construction geometry |
| `polyline` | `points`, `closed` | polygon/shape outlines |
| `arc` | `center`, `r`, `start_deg`, `end_deg` | CCW angle sweep |
| `slot` | `p1`, `p2`, `width` | semicircular caps + parallel straight edges |
| `center_mark` | `center`, `size` | crosshairs |

Parametric values are numbers or formulas prefixed by `=`: `"=bolt_circle_diameter/2"`. Formulas are parsed safely: arithmetic, `pi`, `sin`, `cos`, `radians`, `sqrt`, etc.; arbitrary Python code is prohibited.
